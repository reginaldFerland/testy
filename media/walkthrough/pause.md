# Pause, resume and debug

- Click the Testy status bar item for actions: pause or resume, run affected tests now, refresh, cancel, clear coverage and reset caches.
- Pausing is remembered for this workspace without editing your settings. While paused, a **continuous run** started from Test Explorer keeps its tests running on save.
- Use the **Debug** profile in Test Explorer to debug tests. It requires the C# extension and runs each selected project in one process without coverage.
